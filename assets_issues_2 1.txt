1) When **All** is selected, the Asset Allocation graph in the Asset Page displays the overall portfolio allocation using a doughnut chart, providing a consolidated view of all asset categories. When a specific asset category is selected, the portfolio allocation chart is replaced with an asset-specific doughnut chart showing the internal distribution of that asset. For example, selecting **Equity** displays the allocation across stocks such as Infosys (40%), IRCTC (30%), HDFC Bank (20%), and TCS (10%), while selecting **Mutual Fund** shows the distribution across individual fund schemes. This drill-down approach enables users to seamlessly move from portfolio-level insights to detailed asset composition.

2) Edit Asset Validation Requirement - Only fields that were originally entered by the user during asset creation should be editable in the Edit Asset screen. System-generated values, auto-calculated fields, asset identifiers, and other non-user-entered information should remain read-only. For example, in a Real Estate asset, users should be able to edit details such as Property Name, Area, Location, Current Estimated Value, and Notes, while unnecessary fields or system-derived information should not be presented for editing. This ensures a cleaner user experience and prevents accidental modification of critical asset data.

4) Asset Details Screen Enhancement - When a user clicks on an individual asset from the Asset Table, the Asset Details screen should display not only the standard performance metrics but also all asset-specific information captured during asset creation. Along with metrics such as Invested Amount, Current Value, Profit/Loss, Return Percentage, and CAGR, the screen should dynamically display fields relevant to the selected asset type. For example, a Mutual Fund should display Units Held, Purchase NAV, Investment Date, ISIN Code, NSE/BSE Ticker, and SIP details, while a Fixed Deposit should display Principal Amount, Interest Rate, Start Date, Maturity Date, FD Account Number, and Nominee details. The displayed information should adapt based on the selected asset type to provide a complete view of the asset.
